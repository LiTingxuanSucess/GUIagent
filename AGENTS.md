# Agent Instructions

## Text Encoding Rules

This workspace contains Chinese source comments, YAML, Markdown, and OCR text. Treat all project text as UTF-8.

Before reading or writing files on Windows:

- Do not trust PowerShell `Get-Content` display if Chinese text looks garbled. The file may still be valid UTF-8 while the console code page is not.
- Prefer Python UTF-8 reads for inspection:
  `py -3.11 -c "from pathlib import Path; print(Path('path').read_text(encoding='utf-8-sig'))"`
- When using PowerShell output, first force UTF-8:
  `[Console]::OutputEncoding=[System.Text.UTF8Encoding]::new($false); $OutputEncoding=[System.Text.UTF8Encoding]::new($false)`
- Never "fix" Chinese mojibake based only on terminal rendering. Confirm by reading bytes or using `Path.read_text(encoding='utf-8-sig')`.
- When editing files manually, use `apply_patch`. Do not rewrite UTF-8 files through commands that use the system ANSI code page.
- For JSON/YAML/Markdown/Python generated by scripts, always pass `encoding='utf-8'` or `encoding='utf-8-sig'` explicitly.

For `WXWorkAgent`, run this check after text-heavy edits:

```powershell
py -3.11 tools\check_text_encoding.py
```

If the checker reports mojibake, inspect the exact file and line with UTF-8 reads before applying a correction.
