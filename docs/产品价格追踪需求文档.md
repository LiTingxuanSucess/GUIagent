## 2. 业务流程

### 2.1 进入平台首页

进入目标平台首页后，按店铺搜索。

目标店铺类型：

- 天猫：品牌官方旗舰店
- 京东：京东自营或品牌官方旗舰店
- 抖音：品牌旗舰店

### 2.2 进入品牌官方店铺

进入品牌官方旗舰店后，在店铺内搜索品牌系列名。

示例：

- 品牌：杜蕾斯
- 系列：001
- 店铺内搜索词：`001`

### 2.3 按销量排行锁定代表产品

店铺内搜索后，按销量排行，锁定重点系列的代表产品。

要求：

- 优先选择官方店铺内的销量排序结果。
- 代表产品不是简单取第一个，需要结合系列匹配判断。
- 对“超薄”“玻尿酸”“情趣”等宽泛系列，销量第一的商品可能不是目标系列，需要二次筛选。

### 2.4 进入商品链接并记录价格

进入商品链接后：

- 选择链接主图产品。
- 记录到手价格。
- 保存截图。
- 记录到手片数。
- 计算到手片单价。

计算公式：

```text
到手片单价 = 到手价（含券） / 到手片数
```

## 6. 当前差距

### 6.1 数据字段差距

需要新增或拆分的字段：

| 新字段 | 目的 |
| --- | --- |
| `tracking_date` | 对应“追踪日期”，从 `captured_at` 派生也可以。 |
| `store_label` | 输出“天猫官旗 / 京东自营 / 京东官旗”等业务口径。 |
| `main_product_name` | 对应“链接主品”。 |
| `product_combo` | 对应“链接产品组合”。 |
| `list_price` | 对应“划线价”。 |
| `final_price_with_coupon` | 对应“到手价（含券）”，避免和普通可见价混淆。 |
| `piece_count_source` | 记录片数来自 SKU、标题、详情参数还是人工复核。 |
| `detail_screenshot_path` | 单商品详情截图，区别于搜索页截图。 |
| `source_page_screenshot_path` | 搜索页截图。 |
| `official_store_match` | 记录是否命中官方店铺白名单。 |

### 6.2 流程差距

当前 CloakBrowser 低频 PoC 已验证“列表可安全抓取”，但还没满足完整业务流程：

1. 店铺搜索。
2. 进入官方旗舰店/自营店。
3. 店铺内搜索系列。
4. 按销量排序。
5. 进入详情页。
6. 选择或确认主图产品。
7. 解析组合和片数。
8. 截取详情页价格证据。

### 6.3 Web 页面差距

现有 Web 页面有两个问题：

- 只读取 `exports/*/taobao_results.json`，还不能直接读取京东/天猫 Cloak 输出。
- UI 文案和部分源码存在 mojibake，需要在改造前统一 UTF-8 修复。

## 7. 建议实现路线

### Phase 1：先让 Web 页面接入 Cloak 三平台列表结果

目标：

- Web 能展示京东、天猫、淘宝三类 Cloak probe 输出。
- 统一字段到 `ProductSnapshot`。
- 页面筛选支持 `jd`、`tmall`、`taobao`。

优先补字段：

- `brand`
- `series`
- `tracking_date`
- `store_label`
- `source_page_screenshot_path`

### Phase 2：补最终表格导出

新增统一 CSV/XLSX 导出字段：

| 店铺 | 品牌 | 系列 | 追踪日期 | 链接主品 | 链接产品组合 | URL | 截图 | 划线价 | 到手价（含券） | 到手片数 | 到手片单价 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

列表 PoC 阶段可先输出空值：

- 链接主品
- 链接产品组合
- 划线价
- 到手片数
- 到手片单价
- 详情截图

### Phase 3：低频详情页采集

先从京东开始，因为本次京东登录态正常且未触发风控。

策略：

- 每次只进 1 个详情页。
- 等待 15-30 秒。
- 只截图和读取页面文本。
- 不点击 SKU，不点击优惠券。
- 从默认选中 SKU 解析标题、价格、组合、片数。

### Phase 4：官方店铺流程

建立品牌官方店铺白名单：

```yaml
杜蕾斯:
  jd:
    - durex杜蕾斯京东自营旗舰店
    - 杜蕾斯官方旗舰店
  tmall:
    - durex杜蕾斯官方旗舰店
    - durex杜蕾斯旗舰店
```

再实现：

- 店铺搜索。
- 店铺内搜索系列。
- 官方/自营优先选择。

### Phase 5：系列筛选规则

对宽泛系列建立规则：

- 超薄：包含 `超薄`、`薄`，排除明显非目标促销/组合噪音。
- 玻尿酸：包含 `玻尿酸`、`水润`。
- 情趣：包含 `情趣`、`凸点`、`螺纹`、`颗粒` 等，但需要人工确认边界。
- 持久：包含 `持久`、`延时`、`苯佐卡因`。

低置信度商品进入人工复核，不自动进入最终表。

## 8. 结论

除抖音外，当前能力可以满足“搜索列表级价格追踪”的一部分需求：

- 京东、天猫、淘宝都能用 CloakBrowser 低频抓列表。
- URL、店铺、标题、可见到手价、销量文本可以输出。
- 现有 Web 页面已有价格追踪展示雏形。

但距离 PPT 的最终表格还有关键差距：

- 还没稳定执行“官方店铺内搜索 + 销量排序”主流程。
- 还没稳定进入详情页提取“链接主品 / 产品组合 / 划线价 / 到手片数 / 详情截图”。
- Web 页面还没接入京东/天猫 Cloak 结果。

因此当前状态判断：

```text

淘宝：列表级满足，但登录态显示未登录；详情级需谨慎。
抖音：本轮未评估。
```
